# Что заказать на склад

В файле [inventory.json](data/inventory.json) хранится список товаров. У каждого товара есть название `name`, текущий остаток `quantity` и желаемый минимальный запас `minimum`. Напишите самостоятельную программу в `main.py`, которая читает этот файл и сохраняет список для закупки в другой файл — `data/restock.json`.

Программа запускается из папки с `main.py`.

В список закупки попадают только товары, у которых остаток меньше минимального запаса. Для каждого такого товара сохраните только `name` и `to_order` — сколько единиц нужно заказать, чтобы запас стал равен минимальному. Сохраните порядок товаров из исходного файла. Если закупать нечего, результатом должен быть пустой JSON-массив `[]`.

Пример `data/inventory.json`:

```json
[
  {"name": "Notebook", "quantity": 2, "minimum": 5},
  {"name": "Pen", "quantity": 10, "minimum": 10},
  {"name": "Folder", "quantity": 0, "minimum": 4}
]
```

Для этих данных `data/restock.json` должен содержать:

```json
[
  {"name": "Notebook", "to_order": 3},
  {"name": "Folder", "to_order": 4}
]
```

Оба файла находятся в папке `data` рядом с `main.py`. Исходный файл существует, содержит корректный JSON в UTF-8 и может содержать пустой список. Названия непустые и не повторяются; возможны пробелы, кавычки и буквы разных языков. Остатки и минимальные запасы задаются от 0 и выше, без дробной части. Проверять ошибки данных не нужно.

Исходный файл должен остаться без изменений. Создайте файл результата, если его нет, или полностью замените его прежнее содержимое. Результат сохраните в UTF-8. Отступы, порядок полей внутри одного товара и представление букв напрямую или через JSON-последовательности `\u` можно выбрать самостоятельно.

Ввод с клавиатуры не нужен. После сохранения выведите сообщение на английском с именем файла, например:

```text
Restock list saved to data/restock.json
```

Это пример формулировки; другой текст сообщения допустим.
