# Профиль занятий

Учебное приложение должно запоминать настройки студента. Напишите самостоятельную программу в `main.py`, которая последовательно спрашивает имя, количество минут занятий в день и нужны ли напоминания (`yes` или `no`).

Программа запускается из папки с `main.py`.

Имя непустое, в нём могут быть пробелы, кавычки и буквы разных языков. Время задаётся в полных минутах от 1 до 240. Ввод всегда соответствует условию; проверять ошибки ввода не нужно.

Сохраните данные в `data/profile.json` в папке `data` рядом с `main.py`. Если папки `data` нет, программа должна создать её. Если файла нет, он должен появиться. Если файл уже есть, полностью замените его содержимое настройками текущего запуска.

В JSON должны быть только три поля: `name` — введённое имя, `daily_minutes` — количество минут, `reminders` — `true` для ответа `yes` и `false` для `no`. Сохраните значения без потерь, в кодировке UTF-8. Отступы, порядок полей и представление букв напрямую или через JSON-последовательности `\u` можно выбрать самостоятельно.

Пример диалога:

```text
Enter your name: Tom
Enter daily study minutes: 30
Enable reminders (yes/no): yes
Profile saved to data/profile.json
```

Содержимое `data/profile.json` после этого запуска:

```json
{
  "name": "Tom",
  "daily_minutes": 30,
  "reminders": true
}
```
