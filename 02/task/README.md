# Карточка мероприятия

Организатор прислал файл [event.json](data/event.json). Напишите самостоятельную программу в `main.py`, которая читает этот файл и показывает название мероприятия (`title`), место проведения (`place`) и количество свободных мест (`free_seats`).

Программа запускается из папки с `main.py`.

Файл находится в папке `data` рядом с `main.py`. Это корректный JSON в UTF-8. В нём всегда есть три указанных поля: непустые название и место, а также количество свободных мест от 0 и выше, без дробной части. Текст может содержать пробелы, кавычки и буквы разных языков. Обрабатывать отсутствующий или повреждённый файл не нужно.

Данные нужно получать из файла при каждом запуске: организатор может изменить их, сохранив структуру. Не изменяйте исходный файл и не создавайте новые файлы. Ввод с клавиатуры не нужен.

Покажите каждое значение с понятной подписью на английском. Порядок строк и формулировки подписей можно выбрать самостоятельно; текст в примере — один из вариантов. Нужно показать отдельные сведения о мероприятии, а не весь JSON-документ одним фрагментом.

Для приложенного файла результат может выглядеть так:

```text
Event: Python Meetup
Place: Room 204
Free seats: 12
```

Если свободных мест нет, всё равно покажите их количество — `0`.
